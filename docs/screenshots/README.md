# Screenshots

All images were captured from a **disposable demo vault** at 1480×940, not from a real ledger. They
exist to show the interface and the kind of information each module reports; the numbers are
demonstration data only.

| Page | File | What it shows |
| --- | --- | --- |
| Dashboard | [`dashboard.png`](dashboard.png) | Cash, receivables, invested value, liabilities, net worth and recent activity. |
| Income | [`income.png`](income.png) | Income received, average per month, net cash flow, savings rate, income versus spending by month, expected-versus-received per source, income by account and category. |
| Transactions | [`transactions.png`](transactions.png) | Searchable ledger with kinds, status, splits, refunds, reversals and duplicate detection. |
| Accounts | [`accounts.png`](accounts.png) | Balances per account in their own currency, with base-currency equivalents. |
| Budgets | [`budgets.png`](budgets.png) | 28→27 cycle budgets, allocations and spend read from the ledger. |
| Savings | [`savings.png`](savings.png) | Savings goals and contributions recorded outside the ledger. |
| Investments | [`investments.png`](investments.png) | Manually recorded instruments, trades and valuations. |
| Liabilities | [`liabilities.png`](liabilities.png) | Outstanding principal, payments and payoff progress. |
| Net worth | [`net-worth.png`](net-worth.png) | Manual snapshots, linked debts and money-lent receivables. |
| Analytics | [`analytics.png`](analytics.png) | Monthly flow, expense and income categories, payees. |
| Calendar | [`calendar.png`](calendar.png) | Actual posted and reconciled activity for a month. |
| Journal | [`journal.png`](journal.png) | Free-form dated notes stored in the encrypted vault. |
| Health | [`health.png`](health.png) | Weighted financial-health components with unavailable parts excluded. |
| FI calculator | [`fi.png`](fi.png) | FI number, coast number, projection and explicit assumptions. |
| Financial lab | [`lab.png`](lab.png) | Compound projection, loan amortization and inflation. |
| Imports | [`imports.png`](imports.png) | CSV/XLSX/OFX/QIF preview, mapping, validation and duplicate detection. |
| Backups & exports | [`backups.png`](backups.png) | Verified encrypted backups and Argon2id + ChaCha20-Poly1305 exports. |
| Settings | [`settings.png`](settings.png) | Currency, locale, appearance, exchange rates, integrations status and audit trail. |

The images are regenerated by navigating the running app and capturing each route; they are
documentation, not test fixtures.
